# taa — 时域累积阴影的拖尾–闪烁权衡

移动物体的阴影边缘出现拖尾、停下即消失：时域累积（TAA）把上一帧的阴影
结果按权重混入当前帧，物体移动后旧结果没有被立即替换，残留在边缘后方。
本模块用一维扫描线模拟定量回答：历史权重 β 最大能取多少。

## 模型

扫描线 1024 px，影子长 `L_shadow = 40 px`，边缘位置每帧右移 v px，
shadow-map 亚像素抖动 ±0.15 px（LCG、全程同种子），盒式 PCF（k=3）软化边缘。

### 1. 混合权重表达式（EMA）

```
C_t = β·H_{t−1} + (1−β)·I_t
H_t = C_t
```

- `I_t`：当前帧 PCF 可见性（0–1）
- `H_{t−1}`：上一帧累积结果
- β：历史帧权重；(1−β)：当前帧权重。β=0 即关闭时域累积

### 2. 拖尾长度与速度、权重的关系

边缘移走后，被腾空像素每帧只乘 β，n 帧前的旧结果残留 βⁿ。
取残留阈值 ε = 0.10（低于此值肉眼不可见），等效帧数

```
N_eff(β) = ln(ε) / ln(β)          （β=0 时 N_eff=0）
```

拖尾像素长度：

```
L_trail = v · N_eff(β)
```

### 3. 权重上限反解

约束「拖尾不超过影子的十分之一」：`L_trail ≤ L_shadow/10 = 4 px`

```
β_max = ε^(v / L_budget) = exp(ln(ε) · v / L_budget)
```

| 速度 v (px/帧) | β_max |
|---|---|
| 0.25（慢） | 0.866 |
| 2.00（中） | 0.316 |
| 6.00（快） | 0.032 |

速度越快，允许的历史权重越小。

## 实验协议（`src/taa.c`）

每档速度 × 50 个 β 网格（0.00–0.98）：

1. 静止预热 300 帧（EMA 进入稳态）；
2. 匀速移动 120 帧，跳过前 30 帧瞬态后统计边缘左侧残留 ≥ ε 的像素数，
   对帧取平均得实测拖尾；
3. 物体停下、沉降 150 帧；
4. 静止测量 300 帧，边缘两像素相邻帧差 > 0.05 记一次闪烁事件。

## 实测结果

```
speed   beta_max    beta*   trail_p   trail_m    flick   conflict
slow       0.866     0.86     3.817     2.911        0          0
medium     0.316     0.30     3.825     2.000      231          1
fast       0.032     0.02     3.532     0.000      163          1
```

- `trail_p`：解析预测 v·N_eff；`trail_m`：模拟实测。实测系统性偏小，
  因为解析式假设残留从 1 开始衰减，而 PCF 软边像素被腾空时起点只有
  1/3 覆盖度，且像素计数按整数取整——解析式是保守上界，设计仍按它卡。
- 慢速：β*=0.86 同时满足拖尾 ≤4px 与零闪烁，无冲突。
- 中/快速：满足拖尾预算的 β* 压不住抖动，闪烁分别为 **231、163 次**；
  反过来取零闪烁所需的 β=0.82，拖尾达 **21.0 / 54.7 px**，远超预算。
  两条曲线没有公共交点——定权策略不可两全。

### 冲突时的让步

定权下**让闪烁给拖尾**：拖尾是硬性画面缺陷（用户直接可见的鬼影），
预算 4px 不让；让步实测值即中速 231 次、快速 163 次闪烁/300 帧。

### 运动自适应策略（推荐）

运动中按速度限权 `β_move = min(β_max(v), 0.98)`，检测到静止后恢复
β=0.98 抑制噪声：

| 速度 | β（运动中） | 拖尾实测 | 闪烁（静止段） | 停下后残留 |
|---|---|---|---|---|
| 0.25 | 0.866 | 3.07 px | 0 | ≤1 个 PCF 软边 texel |
| 2.00 | 0.316 | 2.00 px | 0 | ≤1 个 PCF 软边 texel |
| 6.00 | 0.032 | 0.00 px | 0 | ≤1 个 PCF 软边 texel |

三档速度拖尾全部达标、闪烁为零，且停下后历史鬼影在数帧内衰减完
（仅剩 PCF 本身的 1/3 覆盖半影 texel，与历史无关）。
