# 缺陷分类学（基于 mini-shadow-lab @ 928c3a7 的真实代码面）

「黑帧」在本仓库的可定义形式：**某个合法输入让某条判定走到"失败即黑"的一侧**，
且该输入只在特定相机/场景参数下出现，因此线上呈低概率。

判定链只有两处会"失败即黑"：
- `shadowmap/src/shadowmap.c:43` `in_shadow(frag,map,bias) = frag-bias > map`：
  map 侧取到退化值（0 / NaN / 未写区）时，整片被判为遮挡 → 全黑。
- `cascade`→`pcf` 的 texel/penumbra 链：`texel_world` 或 `penumbra_texels`
  返回 ≤0 / inf / NaN，下游把它当有效 texel 尺寸用 → 采样窗口退化为 0 或扫穿
  → 整片阴影/无阴影。

## 同族（BH）——低概率、经稀有参数触发、失败即黑
| id | 位置 | 缺陷 | 稀有性来源 | 可判定层 |
|----|------|------|-----------|---------|
| B1 | cascade.c:15-27 + 30-35 | `build()` 失败返回 -1 **不初始化 `c->n`**；消费者 `idx >= c->n` 读到未初始化计数 → `splits[idx]` 越界读随机值 → 负/零 span | 仅当**首个** build 调用失败且结构体未清零 | 运行时（值取决于栈）|
| B2 | cascade.c:19-24 | 极端 `far/near` + λ 下 float32 使相邻 split 相等/回退，span=0 | 取决于 near/far/n/λ 场景参数 | 评审（场景参数）|
| B3 | pcf.c:9,22 | `DepthMap.d[MAXK*MAXK]` 但 `pcf` 不校验 `w,h<=MAXK`；`sy*m->w+sx` 越界读 | 当分辨率 > MAXK 且 Core 正巧按大图传入 | 编译期（容量/尺寸解耦）|
| B4 | pcf.c:36 | `penumbra_texels` 以 `receiver_depth` 作除数，未防 0 | 接收面恰在光源平面（掠射） | 运行时/编译期（未防零除）|
| B5 | shadowmap.c:16-24 | `mat_ortho` 在 `f==n` 或 `l==r` 时除零 → inf/NaN 矩阵 → 深度全部 NaN | 退化视锥（贴面/零宽） | 编译期（未防零除）|
| B6 | shadowmap.c:43-45 | 深度图清空值与比较方向约定不一致：清 0 且 `frag-bias>0` → 全区遮挡 = 全黑 | 流式/剔除留下未写区域，约千分之一帧 | 评审（清空约定）+运行时 |
| B8 | cascade.c:31-34 | `texel_world` 返回 -1 哨兵，调用方未判负直接当尺寸做除法 | 仅在非法 idx/res 时 | 编译期（返回值未校验）|

## 非本族（OTHER）——会坏，但不是"稀有参数→全黑"
| id | 说明 |
|----|------|
| O1 | `pcf` 越界采样用 clamp 修复（边界恒暗/亮，非偶发） |
| O2 | `(lit*255)/total` 整型截断 → 带状，非黑 |
| O3 | `depth_bias` 掠射时 bias 爆炸 → 过亮（失败即白） |
| O4 | `in_shadow` NaN 比较为 false → 过亮（失败即白） |
| O5 | ε 容差过紧的**测试**不稳定，非运行时缺陷 |

## 干净（CLEAN）——合法重构/加固，不应误报
| id | 说明 |
|----|------|
| C1 | `build` 入口先 `memset` 清结构体 |
| C2 | `MAXK` 改为按传入尺寸分配 |
| C3 | 深度比较封装为命名枚举（语义不变） |
| C4 | 增加 `assert(isfinite())` 但路径本就不产生非有限值 |

> 关键区分（决定宽窄的锚点）：BH 与 OTHER 的差别不是"有没有缺陷"，
> 而是**缺陷在稀有合法输入下是否把判定推到失败即黑的一侧**。
> 窄规则只看"黑侧"，宽规则会连"白侧/永远触发"的一起抓，于是误报上升。
