# biasdir

偏移方向实验：同样的世界位移量，**沿表面法线推**与**沿光照方向推**，
对阴影粉刺（shadow acne）为什么效果完全不同。

`make test` 跑仿真并生成 `results/` 下的 CSV 与图（图需要
`python3 tools/plot.py`，依赖 matplotlib）。

## 1. 几何设定

正交光沿 +z 照射，光照空间深度就是世界 z；一个阴影纹素归一化为一个
世界单位（h = 1）。接收面是倾角 θ 的平面：

```
z(x) = tan(θ) · x          法线 n = (−sinθ, 0, cosθ)
n·L = cosθ                 L = (0,0,1) 为光照方向
```

阴影通道在纹素原点采样深度并按深度缓冲字长取整（floor），主通道连续
插值，两者的亚纹素斜率误差交替变号，形成与平面走向平行的黑纹。

## 2. 两种给法在光照轴上的投影

粉刺是**深度轴上的失败**：只有偏移在光照方向上的投影进入深度比较
（`frag_depth − b > map_depth` 判定为在阴影中），偏移本身不直接起作用。

| 给法 | 世界位移 | 深度投影 b | 横向滑动 Δx |
|---|---|---|---|
| 沿光照方向 | d·L | **b_L = d·(L·L) = d** | 0 |
| 沿法线 | d·n | **b_N = d·(n·L) = d·cosθ** | d·sinθ |

- 迎光面 θ→90°（n·L→0）：b_N = d·cosθ → 0，沿法线推多少，深度比较
  都几乎感觉不到；沿光照方向推则 b_L ≡ d，投影恒定位移量本身。
- 正面 θ=0：cosθ=1，两式重合，b_N = b_L = d，所以正面看不出区别。

## 3. 用「斜面上等效偏移与正面一致」反解方向

要求斜面上的深度投影等于正面的 d：

```
b = d                              （正面基准）
沿光照方向：d_L = b                  ⇒ d_L = d
沿法线：    d_N·cosθ = b            ⇒ d_N = b / cosθ = d / cosθ
```

结论：**偏移量必须按光照方向定义**。沿法线定义时，要在斜面上拿到
同样的深度修正，世界位移得放大 1/cosθ 倍；迎光面 cosθ→0，这个倍数
发散，等价于无法用有限法线偏移消除粉刺。仿真自检
`inverse_normal_requires_b_over_cos` 锁定该反解。

## 4. 反例：沿法线把偏移加十倍，黑纹仍在

80° 迎光面（n·L = 0.1736），d = 10 texel，两种给法各跑一次
（`results/counterexample.csv`）：

| 给法 | 投影表达式 | 实测深度偏移 b | 黑纹像素 | 黑纹面积 |
|---|---|---|---|---|
| 沿光照方向 | b = d | 10.000 texel | 0 | 0% |
| 沿法线 | b = d·cosθ | 10×0.1736 = **1.736 texel** | **24** | **1.172%** |

十倍位移沿法线推，深度投影仍只有 1.736 texel，低于该斜面 6.67 texel
的最坏斜率误差，黑纹原样保留。法线规则要到 d = 34 texel 才清零，
此时横向滑动 d·sinθ = 33.5 texel——影子早已脱离物体。投影表达式
`b = d·cosθ` 与实测黑纹像素数一一对应：投影不足 → 黑纹不消失，
与位移放大多少倍无关。

## 5. 取舍：黑纹面积曲线 vs 影子脱离距离曲线

| 曲线 | 文件 | 读法 |
|---|---|---|
| 黑纹面积随 d 下降 | `results/black_area.png` | 哪条规则先触零 |
| 影子脱离随 d 上升 | `results/detachment.png` | 触零前是否越过 1 texel 预算 |
| 两条配对 | `results/tradeoff.png` | 法线规则脱离预算时黑纹尚未清零 |
| 深度投影本身 | `results/projection.png` | b=d 与 b=d·cosθ 的分叉 |
| 三档最小通过量 | `results/gate_bars.png` | ✕ = 未过 1 texel 脱离预算 |

沿光照方向：斜面正确，正面仍只需很小的偏移（0° 档 d=0 即无斜率
粉刺）。沿法线：正面无害，但斜面的世界位移与横向脱离同时爆炸。

## 6. 三档门槛（黑纹像素必须为 0，脱离 ≤ 1 texel）

数据取自 `results/gate.csv`，2048 个接收子采样/档。角度为法线与光照
方向夹角，等效偏移为该规则清零所需的世界位移（texel）。

| 规则 | 档 | n·L | tanθ | 等效偏移 d | 深度偏移 b | 黑纹像素 | 脱离 texel | 通过 |
|---|---|---|---|---|---|---|---|---|
| light, const | 0° | 1.0000 | 0.000 | 0.000 | 0.000 | 0 | 0.000 | ✓ |
| light, const | 45° | 0.7071 | 1.000 | 1.000 | 1.000 | 0 | 0.000 | ✓ |
| light, const | 80° | 0.1736 | 5.671 | 6.750 | 6.750 | 0 | 0.000 | ✓ |
| light, slope | 0° | 1.0000 | 0.000 | 0.250 | 0.250 | 0 | 0.000 | ✓ |
| light, slope | 45° | 0.7071 | 1.000 | 1.500 | 1.500 | 0 | 0.000 | ✓ |
| light, slope | 80° | 0.1736 | 5.671 | 7.339 | 7.339 | 0 | 0.000 | ✓ |
| normal, const | 0° | 1.0000 | 0.000 | 0.000 | 0.000 | 0 | 0.000 | ✓ |
| normal, const | 45° | 0.7071 | 1.000 | 1.500 | 1.061 | 0 | **1.061** | ✕ |
| normal, const | 80° | 0.1736 | 5.671 | **34.000** | 5.904 | 0 | **33.483** | ✕ |
| normal, slope | 0° | 1.0000 | 0.000 | 0.250 | 0.250 | 0 | 0.000 | ✓ |
| normal, slope | 45° | 0.7071 | 1.000 | 2.121 | 1.500 | 0 | **1.500** | ✕ |
| normal, slope | 80° | 0.1736 | 5.671 | **42.264** | 7.339 | 0 | **41.622** | ✕ |

超出的四档明细：

- normal/const 45°：夹角 45°，等效偏移 1.500 texel，黑纹 0 像素但
  脱离 1.061 texel（>1）。
- normal/const 80°：夹角 80°，等效偏移 34.000 texel，黑纹 0 像素但
  脱离 33.483 texel。
- normal/slope 45°：等效偏移 2.121 texel，脱离 1.500 texel。
- normal/slope 80°：等效偏移 42.264 texel，脱离 41.622 texel。

沿光照方向的两档规则全部通过；沿法线的规则在两个斜面档全部失败，
且失败模式是脱离距离，不是黑纹。slope 规则的深度预算
`b = 0.25 + 1.25·tanθ`，factor 1.25 是本量化器 floor 取整下的最小
通过值（最坏亚纹素误差趋近 tanθ+1）。

## 7. 文件

- `src/biasdir.c` — 仿真与自检，输出三个 CSV

- `results/counterexample.csv` — d=10 反例
