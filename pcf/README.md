## 半影宽度

记：

- `S`：光源宽度；
- `a`：光源到遮挡物的距离；
- `D`：光源到接收面的距离；
- `b = D - a`：遮挡物到接收面的距离。

相似三角形给出的几何半影宽度是

\[
P=S\frac{b}{a}=S\frac{b}{D-b}.
\]

手册近似 `P0 = S b / D` 相当于把分母中的 `-b` 丢掉。经验校正式可写成

\[
P_k=S\frac{b}{D-kb},
\qquad
k=\frac{D}{b}-\frac{S}{P_{\mathrm{meas}}}.
\]

理想锐边、均匀线光源的几何结果对应 `k=1`。给定三组实测宽度
`P1,P2,P3` 后，分别代入上式得到 `k1,k2,k3`；若三者不一致，不存在一个
系数同时精确对准。可按主要取景距离对应的阴影边缘像素数加权，选择加权
最小二乘或最小化最大相对误差的 `k`。

手册近似成立的条件是

\[
\frac{|k|b}{D}\ll 1.
\]

若要求相对几何值偏差不超过 10%，在 `k=1` 时需要 `b/D <= 0.1`
（等价于 `a >= 9b`）。注意这里的 `b` 是遮挡物到接收面的间隙；若输入的
“遮挡距离”是光源到遮挡物的距离 `a`，则应使用 `S(D-a)/a`，且近似条件
变为 `a` 不能远小于 `D`，结论方向相反。
