# pcf

`make test` 跑自检（`pcf`）和半影标定（`calibrate`），CSV 写入 `../artifacts/`。

## 1. 半影软化尺度

面积光源直径 `s`，光源到接收面距离 `D`，遮挡体到接收面距离 `d`
（即光源到遮挡体 `b = D − d`）。相似三角形给出半影宽度

```
w = s · d / (D − d)              # 精确式（以光源到遮挡体 b = D−d 为分母）
w ≈ s · d / D,   当 d ≪ D        # 线性化：半影宽度正比于距离比 d/D
```

投影到阴影图（light 视锥缩放 `scale`、texel 世界尺寸 `texel_world`）后以 texel 计：

```
w_texel = s · (d/D) · scale / texel_world
```

接触点 `d=0` 时半影为零（边缘清晰）；灯靠近墙、`d/D` 变大时半影线性变宽。

## 2. 模糊核随距离比变化的规律

盒式 PCF 核半径 `r` 把硬边摊成宽度约 `2r`（离散图上实测为 `2r+1`）的过渡带。
让过渡带对齐几何半影，核半径必须是半影屏幕投影宽度的函数，而不是固定值：

```
r(d/D) = k · w_texel(d/D)
       = k · (s · scale / texel_world) · (d/D)
```

即 **核半径与距离比 d/D 成正比**；固定核在 `d/D` 增大时欠采样变宽的半影，
边缘退化成噪点，也就是题述故障。

## 3. 三档标定反解 k（而非给固定值）

`src/calibrate.c` 在一维阶梯边阴影图上跑真实 PCF，沿覆盖剖面实测
「最后全暗点 → 第一个全亮点」的过渡带宽度，三档（D=10, s=2, texel=0.1）：

| 档位 | d/D | 理论 w (texel) | 实测宽度 (texel) | 核半径 r | 每像素采样 (2r+1)² | 偏差 |
|---|---|---|---|---|---|---|
| near | 0.40 | 8.0 | 9.0 | 4 | 81 | 12.5% |
| mid  | 0.50 | 10.0 | 11.0 | 5 | 121 | 10.0% |
| far  | 0.75 | 15.0 | 17.0 | 8 | 289 | 13.3% |

三档偏差均 ≤ 15%。过原点最小二乘反解

```
k = Σ wᵢ·rᵢ / Σ wᵢ² = 0.5193      （几何先验 k=0.5，离散量化推高 3.9%）
```

用反解的 k 复算三档，取整后的半径与标定时完全一致（`fitted_k_reproduces_radii=1`）。

**量化失效档（如实报告）**：d/D=0.03 时理论半影仅 0.60 texel，整数半径
下限 r_min=1 实测带 3.0 texel，偏差 400%；固定 r=3 实测 7.0 texel，偏差 1067%。
亚 texel 半影需要 r<1，超出整数 PCF 能力，应交给更高分辨率阴影图或旋转泊松盘。

## 4. 策略：准确度曲线与采样数曲线共同决定

`artifacts/pcf_policy.png`（数据 `policy_sweep.csv`）：

- **自适应核**：误差沿 d/D 锯齿状贴在 15% 线附近（取整量化），采样数从 9
  阶梯升到 289——物理正确，但近处大核开销高；
- **固定核 r=3**：恒 49 taps，但小 d/D 过模糊（误差最高 1650%）、大 d/D 欠
  采样（d/D=0.8 时 56%），两条误差曲线在 **d/D≈0.26** 交叉；
- 工程取舍：d/D 小（接触附近）用 r_min=1 省采样，中段自适应，远端按预算
  钳住 r_max 并接受 >15% 的偏差或换 VSM/软阴影算法。
