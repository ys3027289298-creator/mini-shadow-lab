# bake_realtime

烘焙光贴图（静态阴影）与实时阴影图（角色阴影）的合成。`make test` 跑
数值自检，`python3 tools/plot.py` 重绘 `artifacts/` 下两张图。

## 1. 墙面像素的亮度模型

法线向阳的白墙（albedo=1），亮度分两个物理通道：

| 量 | 含义 | 取值 |
|---|---|---|
| E_d | 直射太阳光辐照度 | 0.80 |
| E_a | 环境/间接光辐照度 | 0.25 |
| sV | 烘焙的直接光可见性（静态遮挡） | 0.90 |
| gAO | 烘焙的环境光遮蔽项 | 0.90 |
| rV | 实时角色直接光可见性（PCF 输出，0..1） | — |

非交界处（角色影响不到的墙面）基线：

```
L0 = Ed·sV + Ea·gAO = 0.80·0.90 + 0.25·0.90 = 0.9450
```

关键事实：**烘焙贴图里没有角色的遮挡，实时阴影图只覆盖角色。**

## 2. 两种合成表达式（直接对比）

相乘管线（直接光相乘，环境光也被实时项再乘一遍）：

```
L_mul = Ed·sV·rV + Ea·gAO·rV = rV·(Ed·sV + Ea·gAO) = rV·L0
```

取最小值管线（直接光取最强遮挡，环境光只吃一次烘焙 AO）：

```
L_min = Ed·min(sV, rV) + Ea·gAO
```

## 3. 接不上处的差异量

物理真值：角色是不透明体，只挡直射光，环境光遮蔽仍是烘焙的那一份，

```
L* = Ed·min(sV, rV) + Ea·gAO = L_min
```

即取最小值管线逐点等于真值。相乘的过暗量 Δ = L_min − L_mul，分两段：

```
rV ≤ sV:  Δ = Ea·gAO·(1−rV) + Ed·rV·(1−sV)
rV >  sV: Δ = (1−rV)·L0
```

两项各对应一种"算错的次数"：

- `Ea·gAO(1−rV)` —— **环境光遮蔽被算两遍**：烘焙 gAO 之外，实时 rV 又压了一次环境光；
- `Ed·rV(1−sV)` —— 直接光在两个次线性算子结合处的损失。

Δ ≥ 0，等号仅在 rV=1（交界外侧）成立。代入实验场景（rV≈0.47）：

```
Δ ≈ 0.25·0.90·0.53 + 0.80·0.47·0.10 ≈ 0.157   (≈ 40 个 8bit 量化级)
```

## 4. 由连续性反解合成方式

要求「交界处亮度与非交界处一致」，即 rV→1⁻ 时合成结果 → L0：

```
取最小值: lim L_min = Ed·min(sV,1) + Ea·gAO = L0        ✓ 连续
相乘:     lim L_mul = rV·L0,  斜率损失 (1−rV)·L0 ≠ 0    ✗ 接缝
```

代数条件是：合成算子 f 必须满足 **f(x,1)=x（单位元）且幂等
f(f(x,y),y)=f(x,y)**。`min` 两条都满足；乘法对 [0,1] 区间的可见性
不满足幂等（0.9×0.9=0.81，每合一次就再暗一次）。故合成方式应为
**取最小值而不是相乘**。工程前提：AO 与直接光可见性必须分通道存储，
不能压进光贴图的同一个通道里。

## 5. 两条决策曲线（见 artifacts/tradeoff_curves.png）

- **过暗程度曲线**：Δ(rV)/q，q=1/255。取最小值恒为 0；相乘在整个
  rV∈(0,1) 区间为 8~57 级，验收阈值 1 级只在 rV≈1 的极窄带内满足。
- **合成开销曲线**：相乘 2 ALU/像素（两次 mul），取最小值 3 ALU/像素
  （cmp+select；GPU 上常合并为单条 MIN 指令，1.5× 是保守上界）。
  实时阴影只覆盖角色周围，屏占比 f 通常 5~15%，帧内总成本
  `(3f + 2(1−f))` 对 `2`：f=10% 时全帧仅 1.05×。小屏占比下两条开销
  曲线几乎重合，而过暗曲线差两个数量级——决策落在取最小值一侧。

## 6. 三档距离的实测结果

半影宽 w = 2d·tan(α)/footprint（α=0.5° 光源角半径，footprint=5cm），
9-tap 固定 PCF 核 + 0.25px 亚像素相位。连续模型在斜坡中点恒给
rV=0.5，与距离无关；三档差异来自固定核对不同宽度半影的离散化：

| 档 | 距离 | 半影(px) | rV | 非交界处 | 交界处真值/min | 交界处相乘 | 物理落差(级) | min 接缝 | 相乘接缝 | 判定 |
|---|---|---|---|---|---|---|---|---|---|---|
| near | 0.2m | 0.07 | 0.4444 | 0.9450 | 0.5806 | 0.4200 | 92.93 | 0.00 | 40.94 | FAIL |
| middle | 5.0m | 1.75 | 0.4763 | 0.9450 | 0.6060 | 0.4501 | 86.44 | 0.00 | 39.76 | FAIL |
| far | 20.0m | 6.98 | 0.4721 | 0.9450 | 0.6027 | 0.4462 | 87.28 | 0.00 | 39.92 | FAIL |

验收口径：**接缝 = 合成结果相对物理真值 L\* 的偏差**，不是投影本身的
落差（角色影子客观存在，真值在交界处本来就比非交界处暗约 87~93 级，
那部分两种管线都有）。阈值 < 1 个量化级。三档全部超标，按要求列出：

- **near（0.20m，硬边工况）**：交界处 0.4200（乘）/ 0.5806（真值），
  非交界处 0.9450，相乘过暗 40.94 级；
- **middle（5.00m，欠采样工况）**：交界处 0.4501（乘）/ 0.6060（真值），
  非交界处 0.9450，相乘过暗 39.76 级；
- **far（20.00m，平滑工况）**：交界处 0.4462（乘）/ 0.6027（真值），
  非交界处 0.9450，相乘过暗 39.92 级。

取最小值管线三档接缝均为 0.00 级（解析式恒等，非数值巧合）。距离
改变的是影子的软硬形状，改变不了接缝的量纲。

## 结论

1. 合成用 `min(sV, rV)`，环境光 AO 只保留烘焙的一份；
2. 相乘方案在三档距离下接缝 39.76~40.94 级，全部超 1 级阈值，否决；
3. 额外成本是每覆盖像素 +1 ALU，典型屏占比下全帧开销 1.05× 以内。
