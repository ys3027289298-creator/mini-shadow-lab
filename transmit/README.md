# transmit

`make test` 跑自检。透明物体的阴影：透射（transmittance）阴影图。

## 1. 透射阴影的表达式

光线穿过吸收介质，走过 `ds` 强度衰减 `dI = -σ I ds`：

```
dI/ds = -σ I(s)        I(s) = I(0)·exp(-σ s)
```

穿过厚度为 `d` 的平板，透过率 `T` 与光学厚度 `τ` 为

```
T(d) = exp(-σ d)       τ = σ d         （比尔-朗伯定律）
```

多层玻璃（厚度 `d_1 … d_n`）连乘，指数相加：

```
T_total = ∏ exp(-σ d_i) = exp(-σ · Σ d_i)
```

这里只算吸收衰减，不含界面菲涅尔反射（斜入射会多一项 `(1-R)²`，本模块不建模）。

## 2. 阴影贴图里存什么

关键差别：**存"光穿过多少"而不是"最近的深度"**。

| | 深度阴影图 | 透射阴影图 |
|---|---|---|
| 每个 texel 存 | `min(z)`，最近遮挡面深度 | 累计透过率 `T_k = exp(-Σ_{j≤k} σ d_j)`，每层一个 |
| 写入 | `min` | 沿光路逐层乘（等价于光学厚度累加后取 `exp`） |
| 查询 | `z_frag - bias > z_map ? 0 : 1`，比较 | 取接收点所在层的 `T_k`，相乘 |
| 输出 | 硬 0/1 | [0,1] |
| 玻璃后的地板 | 0，全黑 | `exp(-τ)`，偏淡的影子 |
| 边缘由什么决定 | 几何轮廓 | 层切分（层越细，部分覆盖越准） |
| 开销 | 每 texel 1 个深度 | 每层 2 字节（量化 1/4096） |

深度图只有一个"最近面"，玻璃后面的接收点一定满足 `z_frag > z_map`，只能给出全黑；
它根本没有"有多少光穿过"这个量。透射图第 `k` 层存 `T_k = ∏_{j≤k} exp(-σd_j)`，
接收点按光路长度选层，用乘代替比较。

深度图直接存 `T` 也不行：`T` 不可比较取最小，遮挡关系靠乘法合成，
所以必须**逐层累加光学厚度**，即

```
T_k = exp(-Σ_{j=1..k} σ d_j)      T_k = T_{k-1} · exp(-σ d_k)
```

两种存法在查询上的函数签名也不同：`xmt_depth_style_lit(z_min, z_frag, bias) -> {0,1}`
对同一块玻璃、同一个地板返回 `0`；`xmt_lit_fraction(map, path) -> T` 返回 `0.631`。

## 3. 反解吸收系数

实测三档玻璃（功率计，约 1% 噪声）：

| 厚度 d (m) | 实测 T | 理论 `exp(-σd)` | 偏差 |
|---|---|---|---|
| 0.004 | 0.91759 | 0.91610 | 0.16% |
| 0.006 | 0.87284 | 0.87682 | 0.45% |
| 0.010 | 0.80493 | 0.80326 | 0.21% |

由 `T_i = exp(-σ d_i)` 取对数，`σ = -Σ d_i ln T_i / Σ d_i²`（对数域、过原点的最小二乘）：

```
σ = 21.91 m⁻¹
```

单点反解分别为 21.50 / 22.67 / 21.70 m⁻¹，三者相差约 ±3%，正是测量噪声；
联合拟合把噪声压到 21.91。三档偏差都远低于一成（最大 0.45%），
自检逐档断言 `dev ≤ 10%`，任一档超出时会打印该档厚度、实测透过率和单点反解的 σ。

（上面的 σ 是在这套测量夹具上反解的；换一批玻璃或换波长就按同一公式重新拟合，
`XMT_DEFAULT_SIGMA = 21.9` 只是缺省值。）

## 4. 层数取舍

按厚度累加物理正确，但层数越多越贵；单层近似快，但边缘错。

截断误差（只用前 n 层与整叠的透过率相对差）：

| 层数 n | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| 前密后疏切分 | 0.389 | 0.245 | 0.141 | **0.068** | 0.022 | 0 |
| 均匀切分 | 1.990 | 1.402 | 0.930 | 0.550 | 0.245 | **0** |

- 10% 预算线：前密后疏 4 层就过，均匀切分要 6 层。
- **单层**：误差 39%（前密后疏）/ 199%（均匀）；且轮廓处只能把"部分穿过的厚度"
  二选一。以半厚度为例，真实 `T(0.0105)=0.795`，单层只能给 1.0 或 0.631，
  边缘相对误差 20.6% / 25.9% —— 这就是"边缘错"。
- 开销随层数线性增长（每层 2 字节，6 层 12 B/texel）。

**定层数 = 6，切分前密后疏**：均匀切分要到 6 层才进入 10%，前密后疏 4 层就够；
取 6 对两种切分都留有余量（前密后疏 5 层 2.2%，6 层为 0）。
若算力紧张，可降到 4 层（前密后疏，误差 6.8%），代价是边缘过渡变粗。

## 5. 接口

```c
float xmt_transmittance(float sigma, float thickness);          /* exp(-σd) */
int   xmt_fit_sigma(const float *d, const float *T, int n, float *sigma);
int   xmt_fit_sigma_one(float d, float T, float *sigma);

int   xmt_slab_init(xmt_slab *s, float sigma, const float *thickness, int n);
int   xmt_store(xmt_map *m, const xmt_slab *s, int layers);     /* 存累计 T */
float xmt_lookup(const xmt_map *m, int level);
float xmt_lit_fraction(const xmt_map *m, float path);           /* 按光路选层 */
float xmt_depth_style_lit(float z_min, float z_frag, float bias); /* 对照 */
```

`xmt_slab` 每层的 `od = σ·d` 可加；`xmt_store` 沿层累加光学厚度后存 `exp(-od)`，
量化到 1/4096。光学厚度上限 8（`e^-8 ≈ 3.4e-4`），超过按 8 截断，避免下溢。
