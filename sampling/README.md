# sampling

`make test` 跑自检。

模型用 `rho = w / Delta s` 表示细结构横向宽度与阴影采样间距的分辨比：
`rho < 1` 时一个采样格可同时覆盖鼻子的两个面，深度在采样阶段塌缩。程序扫描
网格相位、测量最坏连续条纹宽度，并按 `W_stripe <= Delta s / 2` 验收；超档会
打印 `EXCEED ... chosen=<method>`。

选型曲线比较：

- 局部加密：若允许阴影内存翻倍（面密度 `K=2`，间距变为 `Delta/sqrt(2)`），
  则 `rho >= 1/sqrt(2)` 的档位可恢复采样信息；
- 法线接触阴影：不增加阴影图内存，适合更细的局部结构，但保真度随结构尺度
  `w/R_c` 下降，不能替代大结构的投射阴影。
