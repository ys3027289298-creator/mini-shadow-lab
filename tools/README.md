# tools — 级联阴影接缝分析

量化两级交界处的软化跳变，并反解「跳变不超过 10%」时各级阴影贴图的分辨率配比。
模型与 `cascade/`、`pcf/` 两个模块严格一致：分割用 practical split，PCF 用固定 texel 半径。

- `make` 构建 `seam_analyze`
- `make analyze` 打印三档视距的完整文字报告
- `make csv` 重新生成 `../artifacts/` 下的 CSV
- `make chart` 由 CSV 生成自包含交互报告 `../artifacts/seam_tradeoff.html`

## 1. 每级 texel 的世界尺寸

practical split（与 `cascade/src/cascade.c` 相同，λ 是对数/均匀混合系数）：

```
split_i = λ · near · (far/near)^(i/n)  +  (1−λ) · (near + (far−near)·i/n)
span_i  = split_i − split_(i−1)                 （split_−1 = near）
```

第 i 级阴影贴图分辨率为 R_i 个 texel，则单个 texel 覆盖的世界深度尺寸：

```
t_i = span_i / R_i
```

固定半径 r 的 PCF（与 `pcf/src/pcf.c` 一致）在世界空间的滤波核宽度是
`w_i = (2r+1)·t_i`。半径以 texel 计、各级相同，所以 (2r+1) 在比值里会约掉。

## 2. 接缝为什么可见，以及跳变量

接收面跨过第 i / i+1 级交界处，两侧 texel 尺寸不同、PCF 世界核宽不同，
同一处半影的软化程度于是发生跳变。跳变量就是两级 texel（也是核宽）之比：

```
J_i = w_(i+1)/w_i = t_(i+1)/t_i
     = (span_(i+1)/span_i) · (R_i/R_(i+1))
```

**关键结论：各级用相同分辨率时 R_i = R_(i+1)，跳变 J_i = span_(i+1)/span_i，
完全由几何决定，把三张图一起加大分辨率也消除不了接缝——只能改变各级配比。**

要求跳变不超过一成（J_i ≤ 1.10），反解出相邻级分辨率配比：

```
R_(i+1)/R_i  ≥  span_(i+1) / (1.10 · span_i)
```

把每道接缝都取等号（最省总分辨率的紧约束），并锚定近景级 R0，则通解为：

```
R_i = R0 · span_i / (span_0 · 1.10^i)
```

## 4. 反解出的分辨率配比（跳变 ≤ 10%）

相邻级所需比值与锚定 R0=2048 时的连续最优分配：

| 视距 | 所需 R1/R0 | 所需 R2/R1 | 连续最优 [R0,R1,R2] | 总 texel | 等分辨率总 texel |
|---|---|---|---|---|---|
| 近景 | ≥1.209 | ≥2.229 | [2048, 2477, 5520] | 10,044 | 6,144 |
| 中景 | ≥1.124 | ≥2.650 | [2048, 2303, 6102] | 10,453 | 6,144 |
| 远景 | ≥1.090 | ≥2.806 | [2048, 2231, 6261] | 10,540 | 6,144 |

该分配下每道接缝恰好 +10.0%（见 HTML 报告的数据表，texel 逐级只差 1.10×）。

**固定 6144 预算（不增显存）的等价做法**是按同一形状整体缩放，代价是近景变软：

| 视距 | 预算内分配 [R0,R1,R2] | 近景 texel 变化 |
|---|---|---|
| 近景 | [1253, 1515, 3376] | 0.00869 → 0.01421（+63%） |
| 中景 | [1204, 1354, 3587] | 0.04175 → 0.07103（+70%） |
| 远景 | [1194, 1301, 3649] | 0.08276 → 0.14197（+72%） |

这就是核心取舍：**预算吃满才能在保住近景清晰度的同时让接缝不可见；
预算固定时，接缝不可见是用近景变软换来的。**

## 5. 两条取舍曲线与 2 的幂硬约束

`seam_analyze curve` 输出、`seam_tradeoff.html` 画出两条曲线（横轴=允许的软化跳变，
纵轴=所需总分辨率，近景级 R0 锚定）：

1. **连续最优前沿（任意贴图尺寸）**：容忍度越紧总分辨率越高，全程平滑。
   远景锚定 R0=2048 时，+5% 需 11,257、+10% 需 10,540、+15% 需 9,910、+25% 需 8,860。
2. **严格 2 的幂（相邻级只能相等或翻倍，倍率仅 1× 或 2×）**：离散点，且存在可行性下限。
   第二道接缝需要 2.23×–2.81×，单次翻倍（2×）不够、两次翻倍（4×）又过头，因此
   **任何 2 的幂配比都够不到 +10%**：

| 视距 | 2 的幂能达到的最小跳变 | 对应配比 | 总 texel |
|---|---|---|---|
| 近景 | +22.6% | 2048-4096-8192 | 14,336 |
| 中景 | +45.7% | 2048-2048-4096 | 8,192 |
| 远景 | +54.3% | 2048-2048-4096 | 8,192 |

把级联数加到 4 级也只能把近景最好情况压到 +10.7%，中/远景仍为 +35%/+46%。

## 6. 建议

- **首选：放弃「各级同分辨率」，改用按 span 配比的非 2 的幂尺寸**（现代 GPU 纹理
  支持任意尺寸，或用非方 atlas 分块）。远景可用约 [2048, 2231, 6261]，两道接缝都卡 +10%。
- **若被限制为 2 的幂**：配比无法达标，需在交界处叠加跨级 dither/混合（在一定边缘
  宽度内按深度权重混合两级结果）来掩盖 +22.6%~+54.3% 的软化跳变；或增加级联数配合混合。
- **显存固定为 6144**：按 [1194,1301,3649]（远景）这类比例重分配可满足接缝指标，
  但要接受近景 texel 增大约 72%；是否值得取决于对近景清晰度与接缝可见度的相对要求。
