# stabilize

阴影贴图正交投影矩阵的更新判据与 texel 相位稳定性实验。`make test` 跑自检。

## 模型

沿光源某一轴做一维建模，世界点 `p` 映射到阴影纹素：

```
texel(p) = (p - o) / w
```

`o` 为视锥在光源空间的原点，`w` 为一个纹素的世界尺寸。
`frac(texel(p))` 即 texel 相位：它逐帧变化时，阴影边缘在不同纹素间重新
量化，几何和光源都没变，影子却在抖。

## 三种挂载方式

| 策略 | 原点 `o` | 含义 |
|---|---|---|
| `cam_raw` | `cam` | 视锥原点直接跟相机，无对齐 |
| `light_snap` | `floor(cam/w)*w` | 跟随相机但原点吸附到光源空间纹素网格 |
| `light_fixed` | 场景包围盒边界，只建一次 | 完全锚定光源空间 |

## 结论

- 更新判据：矩阵只由光源位姿与场景包围盒决定，二者不变则矩阵不变
  （`light_fixed_*_rebuilds=0`）。
- 相机空间挂载时相位跳动 `Δφ = frac(Δcam/w)`，每帧都重建。
- 令 `Δφ = 0` 反解：原点必须是 `w` 的整数倍偏移，即锚定光源空间。
- `light_snap` 相位恒为零，重建次数为 `min(fps, v/w)`；相机走出包围盒
  才需要真正重建（重新计算包围盒并重渲染阴影贴图）。
