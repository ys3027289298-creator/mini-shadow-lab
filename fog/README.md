# fog

雾与阴影的合成顺序。`make test` 跑自检，三档雾浓度各测一次。

场景设定（自检里固定不变，唯一变量是雾浓度）：

- 阴影合成**之后**的表面辐射度：受光 `L_lit = 0.80`，阴影 `L_shd = 0.20`
- 无雾阴影对比度 `R0 = L_lit / L_shd = 4.00`
- 视距 `d = 10`，消光系数 `σ`，透过率 `T = exp(-σd)`，雾量 `f = 1-T`
- 雾色 / 散射辐射度 `F = 0.60`

## 1. 雾对阴影的影响表达式

错误做法把雾的散射当作一层亮度，在阴影结果上做 alpha 混合：

```
C_blend(L) = T·L + f·F          // f·F 就是叠加在阴影上的那层亮度
C_lit = T·L_lit + f·F
C_shd = T·L_shd + f·F
```

阴影处和受光处被加上**同一个绝对值** `f·F`，阴影被抬了一个本不存在的亮度地板。

差值对比度（受光−阴影的间隔）被压缩成：

```
C_lit - C_shd = T·(L_lit - L_shd)
压缩比（间隔）= T                        // 浓雾 T→0 时间隔被压没
```

比值对比度被压缩成：

```
R_blend = (T·L_lit + f·F) / (T·L_shd + f·F) < R0
压缩比（比值）= R_blend / R0
             = (T·L_lit + f·F)·L_shd / ((T·L_shd + f·F)·L_lit)
```

两个极限：`fF→0` 时压缩比 → 1（无损）；`T→0` 时 `R_blend→1`、压缩比 → `1/R0`
（阴影与受光糊成一团，这就是"走近也看不清"的代数原因）。

## 2. 正确的顺序：先阴影，后雾

阴影因子必须先算完并已经包含在 `L` 里，雾在最后只做一件事——衰减整体亮度：

```
混合（错误，加法 in-scatter）:  C = T·L + (1-T)·F
乘法（正确，只衰减）:          C = T·L
```

乘法下：

```
C_lit = T·L_lit,  C_shd = T·L_shd
R_mul = C_lit / C_shd = L_lit / L_shd = R0     // 与 T 无关，对比度不被削
C_lit - C_shd = T·(L_lit - L_shd)              // 绝对间隔随整体一起变暗，相对对比不变
```

## 3. 反解：对比度不变 ⇒ 合成必须是乘法

设一般形式 `C(L) = T·L + g(T)`（`g` 是任何形式的加法项，混合法即 `g = f·F`）。
要求对任意 `T` 都有 `R(T) ≡ R0`：

```
(T·L_lit + g) / (T·L_shd + g) = L_lit / L_shd
交叉相乘:  T·L_lit·L_shd + g·L_shd = T·L_lit·L_shd + g·L_lit
⇒ g·(L_shd - L_lit) = 0
⇒ g(T) ≡ 0          （因为 L_lit ≠ L_shd）
```

加法项必须恒为零，唯一解就是纯乘法 `C = T·L`。任何非零加法混合都会随
`T` 下降吃掉阴影对比度，没有调参空间。

## 4. 取舍：两条曲线定合成方式

乘法不是免费的，浓雾下有副作用：

| 曲线 | 乘法 `C=TL` | 混合 `C=TL+fF` |
|---|---|---|
| 对比度 R(T) | 恒为 R0（平线） | 单调跌到 1 |
| 整体亮度 mean(T) | `T·mean0`，T→0 时画面过黑 | `T·mean0 + fF`，T→0 时托在 F |

自检在浓雾档扫了一条混合参数 `α`（`C = TL + α·fF`，α=0 纯乘法，α=1 纯混合），
同时记录对比度曲线和亮度曲线。要求对比度保留 ≥ 90% R0 时，浓雾档解出
`α ≤ 0.002`——雾越浓，加法项的预算越接近零；浓雾发黑只能靠曝光/tonemap
或大气透视分层解决，不能靠把散射加回表面。

> 物理注记：真实大气的 in-scatter 确实存在，渲染方程的严格解就是混合式。
> 本模块按"阴影对比度不随雾浓度变化"这一美术约束推导；若要物理正确，
> 应保留混合式但接受对比度下降，或把 in-scatter 限制在远距离的大气透视层。

## 5. 三档实测（d=10，R0=4.00，保留预算 0.9·R0=3.60）

| 档 | σ | T | 混合-阴影 | 混合-受光 | 混合 R | 乘法-阴影 | 乘法-受光 | 乘法 R |
|---|---|---|---|---|---|---|---|---|
| light | 0.02 | 0.8187 | 0.2725 | 0.7637 | 2.8027 | 0.1637 | 0.6550 | 4.0000 |
| medium | 0.10 | 0.3679 | 0.4528 | 0.6736 | 1.4874 | 0.0736 | 0.2943 | 4.0000 |
| dense | 0.30 | 0.0498 | 0.5801 | 0.6100 | 1.0515 | 0.0100 | 0.0398 | 4.0000 |

乘法三档 R 恒为 4.0000（容差 1e-4）；混合三档全部超出预算，超限明细：

```
OVER sigma=0.02 T=0.8187 阴影=0.2725 受光=0.7637 比值=2.8027
OVER sigma=0.10 T=0.3679 阴影=0.4528 受光=0.6736 比值=1.4874
OVER sigma=0.30 T=0.0498 阴影=0.5801 受光=0.6100 比值=1.0515
```

浓雾档混合的间隔压缩比实测 0.0498，恰等于 T；比值压缩比 0.2629
（R/R0，1 为无损）。
